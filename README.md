# wdm_design
My design, analysis, and layout of a four channel C-Band Wavelength Division Multiplexing (WDM) photonic circuit using silicion add-drop microring resonaotrs aligned to the 100 GHz ITU channels C47 to C44. 

The simulation folder contains the code for the SAX S-matrix models and the analysis of the optimized microring resonance parameters obtained from a coupler half-ring Tidy3D FDTD simulation.

The layout folder contains the notebooks for routing the Rx/Tx chips separately and then connecting the two chips onto one floor plan with multilayer electrical routing, common-ground buses, signal pads, via stacks, and other important features for ensuring the functionality of the WDM design.
